class InvalidTimestampNeighbours(unittest.TestCase):
    def test_invalid_row_between_valid_rows_does_not_crash_and_is_isolated(self):
        r = val([row(1,'2025-01-01','08:00:00'), row(2,'2025-02-30','unknown'), row(3,'2025-01-02','08:00:00')])

Three caveats about the script, all verified from the source:

Hardcoded path. SRC is /home/claude/cs-nrrm/validator/v2.2. To use a different clone location, edit that one line in a copy of my_mutants.py.
Kill criterion. A mutant counts as "killed" on any non-zero test exit, including a crash or timeout, not only an assertion failure. It cannot tell a meaningful failure from a trivial one. The X11 kill, for example, comes from the mutation breaking ordinary dates.
Mutation target. It mutates only a temporary copy, never the repo.
